# ZentixBot — Dashboard tahap 6

Saat disajikan dari proses bot pada `/dashboard/`, fungsi utama bot terhubung; beberapa tab/opsi lanjutan dan AI masih simulasi. Perincian, pengaturan hosting, batasan, dan panduan uji ada di `../DOKUMENTASI-TAHAP-5.md` dan `../DOKUMENTASI-TAHAP-6.md`.

Menjalankan `python3 -m http.server 4174` pada folder ini menghasilkan preview statis tanpa autentikasi: **semua** data dan tindakan adalah contoh. Jangan masukkan token, informasi pribadi, atau data sensitif ke preview dan jangan gunakan sebagai dashboard produksi.
