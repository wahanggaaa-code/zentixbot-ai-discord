# Core — akses perintah di dashboard

Buka **Fitur bot → Core & command access** pada dashboard bot yang sudah login Discord. Owner atau administrator server home dapat melihat kategori, perintah/subperintah yang dimuat bot, status efektif, serta menonaktifkan atau mengaktifkan satu perintah atau kategori setelah konfirmasi. Pencarian memfilter daftar yang dimuat. Ini pengaturan akses bot, bukan daftar hak Discord atau bukti command sudah terdaftar di Discord. Nonaktif kategori juga menonaktifkan perintahnya; mengaktifkan perintah saja tidak mengaktifkan induk/kategorinya. `/commands` dan `/configwizard` beserta subperintahnya dilindungi dan tetap aktif. Perubahan tidak menjamin bahwa Discord, permission, atau layanan eksternal tersedia.

Data dan perubahan API ini saat ini hanya mendukung PostgreSQL yang sehat. Preview statis tidak mengambil data atau memiliki tombol live. API memakai autentikasi ulang keanggotaan owner/admin, origin dan CSRF; respons tidak boleh di-cache. Pembacaan menolak data akses tidak valid dan penyimpanan menolak konflik onboarding. Konflik versi meminta reload. Versi adalah hash konfigurasi guild: perubahan lain dapat menyebabkan konflik; perubahan A → B → A tidak terdeteksi. Jika koneksi terputus saat commit, hasil mungkin tidak diketahui: muat ulang dan periksa sebelum mencoba lagi.

Jalur pengubahan `/commands` dan web pada PostgreSQL kini mengunci baris guild dan menulis hanya objek akses terkait, sehingga perubahan bersamaan dari penulis yang ikut protokol tidak menimpa satu sama lain. Untuk upgrade hentikan seluruh instance lama terlebih dahulu. SQL langsung atau penulis lain yang tidak mengikuti protokol tidak dijamin aman; backend non-PostgreSQL pada jalur Discord lama tidak memperoleh jaminan ini. Pastikan backup teruji. Penyimpanan tidak menyimpan riwayat audit khusus atau melakukan perubahan hak akses Discord. Pengujian lokal memakai PostgreSQL dan mock Discord; deployment dan interaksi Discord nyata masih harus diverifikasi.

Halaman ini tidak berarti seluruh fitur kategori lain sudah terintegrasi; ia hanya mengelola akses perintah yang dimuat, bukan konfigurasi atau data fitur tersebut.
