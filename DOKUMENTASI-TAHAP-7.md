# Tahap 7 — Fondasi AI dan fallback

## Cakupan
Fondasi **teks saja**: Groq, Gemini (endpoint OpenAI-compatible), OpenRouter, dan NVIDIA NIM memakai endpoint HTTPS resmi tetap. Pilih model utama dan opsional satu provider cadangan yang berbeda di AI Studio → Provider & fallback. Ollama, gambar, audio dan tool calling belum didukung; pemilihan model tidak menjamin ketersediaan/kompatibilitas provider. Fitur AI Welcome, Activities, Chat, dokumen, gambar dan Server Builder tetap simulasi Tahap 8. Tidak ada AI yang berjalan otomatis atau membaca pesan Discord pada Tahap 7.

Default nonaktif. Dashboard membutuhkan login Discord serta izin admin/owner server **dan** ID pengguna dalam `OWNER_IDS`; perubahan dan tes wajib CSRF/Origin. API key hanya melalui environment server, tidak melalui browser/database/repo. UI hanya menampilkan apakah masing-masing key terisi, bukan validitasnya. Atur `AI_GROQ_API_KEY`, `AI_GEMINI_API_KEY`, `AI_OPENROUTER_API_KEY`, `AI_NVIDIA_API_KEY` seperlunya; jangan commit `.env` atau membagikan key. Setting tersimpan di PostgreSQL `cache_data`; tanpa database persisten operasi gagal tertutup. Daftar model dan koneksi provider tidak divalidasi saat menyimpan.

Untuk tes nanti: siapkan PostgreSQL, OAuth, HTTPS dan owner sesuai dokumentasi Tahap 5; isi key di environment, restart bot, pilih provider dan model, atur batas, centang persetujuan pemrosesan eksternal, aktifkan dan simpan, lalu klik **Tes koneksi** dan konfirmasi. Tes mengirim prompt contoh tetap, dapat dikenai biaya dan memakai kuota. Teks respons ditampilkan pada halaman admin. Jika utama gagal karena jaringan, timeout, kredensial, model tidak ditemukan, rate limit, error server, atau respons tidak valid, layanan mencoba cadangan jika dikonfigurasi dan memiliki key. Permintaan yang ditolak (misalnya input buruk) dan respons yang difilter tidak diteruskan ke cadangan. Jika semua gagal, hasil error umum tanpa isi respons/secret provider. Tidak ada retry otomatis selain satu kali fallback.

## Batas penggunaan dan privasi
- Kuota permintaan per anggota dan server per hari UTC dihitung secara transaksional di PostgreSQL **sebelum** pemanggilan provider. Kegagalan dan tes tetap dihitung, bukan dikembalikan. Fallback adalah bagian dari satu permintaan tetapi bisa menyebabkan dua panggilan berbayar. Batas ini bukan batas biaya atau total token; batasi anggaran juga pada provider. Ada maksimum empat permintaan aktif **per proses**, timeout per provider, 4.000 karakter input dan batas output yang dikonfigurasi.
- Teks input dikirim ke provider utama dan bisa juga dikirim ke cadangan. Persetujuan owner diperlukan untuk mengaktifkan; pengguna fitur Tahap 8 nantinya juga harus diberi penjelasan dan memberikan persetujuan sebelum mengirim konten. Penyimpanan, pelatihan dan retensi oleh masing-masing provider mengikuti kebijakan provider dan harus ditinjau sendiri. Jangan masukkan data sensitif. Tidak ada jaminan bahwa provider tidak menyimpan input.
- Fondasi tidak menyimpan atau mencatat prompt dan respons. Pengaturan dan penghitung penggunaan menyimpan ID guild, ID user, hari UTC dan jumlah permintaan di database; entri penghitung ID tetap ada hingga dihapus. Backup database ikut menyimpannya. Lakukan kebijakan retensi/penghapusan yang sesuai; menghapus counter pada hari yang sama akan mereset kuota.
- `generate` hanya dipanggil oleh kode server tepercaya dengan ID guild target, ID pengguna sebenarnya, dan `consent:true`; fungsi ini **tidak** memverifikasi keanggotaan Discord atau mengumpulkan persetujuan sendiri. Integrasi Tahap 8 wajib memverifikasi keduanya sebelum memanggilnya, serta menerapkan kebijakan DM/single-guild dan keamanan fitur. Tidak ada endpoint prompt bebas yang diekspos ke browser pada tahap ini.
- Satu proses dianjurkan: pembatasan concurrency di memori tidak terkoordinasi antarproses, meskipun kuota database memakai row lock. Perubahan limit atau nonaktif saat permintaan sedang berjalan tidak membatalkan permintaan yang telah dimulai. Belum ada audit biaya, dashboard riwayat, streaming, moderasi konten tambahan, atau enkripsi database tingkat aplikasi.
